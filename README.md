---

### 🏥 Smart Hospital Monitoring Framework

A real-time hospital monitoring prototype designed around patient
tracking and hospital workflow.

The system includes:

- Doctor/staff authentication
- Patient dashboard
- Patient management
- Backend event handling
- Real-time updates using Socket.IO
- SQLite persistence
- JWT authentication
- Arduino + HC-05 Bluetooth prototype

The hardware prototype sends patient information through Bluetooth,
while the backend processes the incoming data and updates the web
interface in real time.

**Tech:** Node.js • Express • SQLite • Socket.IO • JWT • Arduino • HC-05
